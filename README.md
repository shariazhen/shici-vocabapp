# 拾词 · shici

跨境电商 / 达人 BD 的英语速记本。离线优先的 PWA，装到 iPhone 主屏当原生 App 用。

**线上地址**：https://shariazhen.github.io/shici-vocabapp/

## 功能

- **今日** — 新词闪卡，右甩认识 / 左甩忘了 / 轻点翻面。背面有释义、例句朗读、
  速记（词根拆解 + 联想钩子 + 易混词）和常用搭配。
- **练习** — 七种题型：中译英、听音拼写、听句选词、词语搭配、哪个更地道、
  场景填空、跟读打分。
- **词库** — 50 个电商/外贸/达人 BD 场景词，可搜索、收藏、自己加词。
- **统计** — 五维能力面板（认词/拼写/听力/地道/口语）+ 最弱项建议。
- **设置** — 每日新词量、推送时段、多设备同步、导入导出。

学习数据全在手机本地（IndexedDB），不配后端也能完整使用。

## 雅思 G 类第一版

新增 **24 条原创入门词条、8 个主题**：住房、工作、交通、医疗、教育、环境、社区、科技。它们用于语言学习，不是官方真题或完整的雅思必考词表。

- **今日**：选择雅思、原商务与自建词库或全部词库，安排到期复习、新词、听写／改写和说写微任务。说写草稿按本机日期保存在本机，不自动评分。
- **词库**：按主题筛选；点击词条打开详情，查看搭配、英文释义、易错点和“认识／听写／搭配／运用”练习记录；详情内可播放发音。
- **练习**：新增英文释义识词（同义改写）。每种题型优先复习该题型最近答错的词，再安排练习较少的词。错词本也纳入专项练习错误。
- **数据**：继续使用原 IndexedDB；增补词条内容，不重置已有释义、收藏和复习进度。学习词库选择不隐藏词库页中的其他词条。每日新词配额仍沿用原来的全库每日计数。
- **离线**：新词表已纳入 Service Worker 2.2 缓存。语音合成／识别的可用性取决于浏览器和设备；这些记录不能换算成雅思四科成绩。

前端无需构建，在仓库根目录运行：

```bash
python3 -m http.server 8081 --bind 127.0.0.1
```

浏览器回归验证（需安装 Playwright npm 包和 Chromium）：

```bash
node tests/ielts-smoke.cjs
```

测试默认使用 `/usr/bin/chromium` 和本机 8081 端口，可通过 `CHROMIUM_PATH`、`SHICI_TEST_URL` 覆盖。验证词库迁移、旧进度、筛选、详情、答题去重、错题优先、复习队列、草稿保存与离线重载；测试阻断线上 API 请求，不写生产数据库。

本版没有修改 `config.js`：已有在线查询／同步仍按原配置工作，本机说写草稿不参与云同步。

## 雅思 G 类第二版

在「今日」「练习」或「统计」进入 **雅思训练**。本版增加：

- **书信**：正式维修请求、半正式培训安排、非正式朋友邀请，含三个写作要点、语气提示、表达支架和自查表。建议 20 分钟、至少 150 词。
- **议论文段落**：交通、工作技能、环境三个主题，练习观点—解释—例子。单段建议 70–110 词；这不是完整 Task 2（完整作文至少 250 词，建议 40 分钟）。
- **口语**：Part 1 工作、Part 2 公共设施、Part 3 科技。支持麦克风录音、回听、下载和文字笔记；最长一次 3 分钟。Part 2 的 1 分钟准备由学习者自行计时。
- **练习记录**：按题目保存草稿和自查；点击「保存练习记录」保留当次文本和录音快照，之后修改草稿不会覆盖历史。历史录音可单独下载，当前录音和历史练习可分别删除。
- **四科进度**：手动记录模考、教师反馈、正式考试或自评估计；显示各科最近一次成绩、日期、来源和距 7 分的差距。支持 0–9、每档 0.5，拒绝未来日期；不自动估分，不将词汇成绩换算为雅思分数。

所有题目为原创练习，非官方真题。说写内容没有自动批改，建议结合可靠的教师反馈。本模块使用独立 IndexedDB `shici-training`（drafts / attempts / scores），保留原词库数据库不变。不调用云端 AI 或上传音频，不参与词库同步或 CSV 导出。各类历史展示最近 20 条，累计数量覆盖全部练习。换设备或清理浏览器数据前，请下载需保留的录音，并另行保存重要文字和成绩。

录音需要支持 MediaRecorder 的浏览器、麦克风权限及安全上下文（HTTPS 或本机开发环境）。选择支持的 WebM / MP4 音频格式；不支持录音或拒绝权限时，可继续使用文字提纲和自查。离开训练页或切入后台会停止录音；页面内导航会保存文字草稿，刷新或关闭页面前请点击「保存草稿」。Service Worker 缓存升级为 2.3，包含新训练模块。

新增浏览器验证：

```bash
node tests/ielts-training.cjs
```

该验证使用 Chromium 模拟麦克风测试录音与播放、刷新保存、页面离开时停止、权限拒绝回退，同时覆盖空内容拦截、题目切换、历史快照、成绩输入校验与删除、离线恢复。尚未在 iPhone 真机上验证录音格式与系统后台行为。
